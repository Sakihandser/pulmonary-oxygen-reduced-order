# Capacity response and oxygen compensation

Run `python code/reproduce_coupling.py` from this directory or `python coupling_extension/code/reproduce_coupling.py` from the archive root. The root `python reproduce.py` includes this extension.

The frozen protocol defines an exploratory mathematical analysis after the conditional data comparison. No observations are added or changed. Four result CSVs record response curves, the local sign boundary, coupled recovery roots, and conditional sensitivity to the scaling exponent. Final Figure 6 is generated by code/figures_coupling.py. Eight tests include independent balance solutions and derivative checks.

The fixed-s compensation identity in review_extension is retained for prescribed fractions. For flow-dependent s, recovery points are calculated along one consistent response curve. Section P of Supplementary_Methods and main Equations (9)–(10) give the derivation and feasibility conditions. Formal roots beyond the displayed Q/Q0 range of 0.6–2 are extrapolations, not clinical estimates.
