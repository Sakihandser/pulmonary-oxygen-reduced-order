# Numerical data and code

This supplement contains the code, aggregate inputs and full-precision results supporting the article. Install the recorded dependencies and run from a clean extraction:

```text
python -m pip install -r requirements-lock.txt
python reproduce.py
```

After dependencies are installed, reproduction uses no network. It verifies the distributed SHA256 manifest, regenerates 58 benchmark numerical result CSVs and 23 empirical-extension CSVs, checks main Tables 4–8 at printed precision and exports Figures 1–12, S1 and S2. Run in a disposable copy because generated results change. Numerical comparisons use absolute tolerance 2e-6 plus relative tolerance 1e-8; scalar and semicolon-separated numeric cells are compared elementwise, and nonnumeric text must match exactly. `reproduction_summary.json` records the checks and software environment.

`RESULT_REPRODUCTION_INDEX.md` maps each principal result to full-precision CSV files, calculation scripts and figure exporters. `common_calibration/code/run.py` generates common endpoint/inlet-slope fits, frozen-state comparisons and allocation scans. `common_calibration/code/mechanism.py` generates the dissolved-oxygen controls and signed state maps. The 128-condition reference matrix and separate convention-based comparisons remain part of the reported study.

Other directories supply the hydraulic model and inputs, attributed aggregate source cells, observation maps, structural identifiability and controlled exchange calculations. Main-table CSVs and figure inputs are in `sensitivity/reporting/`. Figure-only export is `python sensitivity/reporting/reproduce_figures.py` from this directory. Supplementary Material S3 supplies the standalone reporting distribution and editable article figures.

Run the tests from this directory:

```text
python -m unittest discover -s tests
python -m unittest discover -s aggregate_analysis/tests
python -m unittest discover -s observation_analysis/tests
```

The optional Windows native pressure-kernel check is `powershell -File sensitivity/code/run_native_alvin.ps1`. The pinned upstream C# source, compilation harness, GPL license and 250 native nodes are supplied. Portable reproduction compares the supplied native nodes without compiling C# on other platforms. This is qualification of a harmonized pressure submodule, not the complete Unity model or patient physiology.

Published observations include attributed aggregate transcriptions and seven recoded individual rows from a published 1979 table. No unpublished participant records or publisher full text are distributed. Source Hb normalization remains unresolved. `LICENSE_DATA.md` and `sensitivity/external_alvin/PROVENANCE.md` record source and license boundaries. Solver checks, assumed output-error bounds and physiological evidence have distinct interpretations.


The bounded-calibration and grid-resolution analyses in S1 Section I are generated by `python robustness/code/run.py` in S2. The five CSVs in `robustness/results/` contain the seven target-offset fits, exact monotone marginal envelopes, their separation counts, all 882 baseline grid verification states, and 21/41/81 grid-resolution comparisons. The one-command S2 run executes these calculations and compares all five CSVs against the distributed values. The numerical allowance remains 1e-7 mL/dL per output; target halfwidth c and output bound e are separate assumed inputs. These are deterministic scenarios, not confidence intervals.

The public commit 7460853b82a8e72bf4ded4b1c94d14a3baaaa676 records the original computational core. The additional robustness analysis is distributed in the present S2 archive, whose release_sha256.json identifies the complete supplied files. This archive is the reproduction source for Section I; the earlier public commit alone does not contain that extension.


The empirical extension is documented in experimental_validation/README.md and SEARCH_AND_EXTRACTION.md. Its protocol, data dictionary fields, source registry, sensitivity, 19 extension tests and Figures 8–11 are supplied locally. Run `python experimental_validation/code/reproduce_empirical.py` to reproduce this part alone. The fixed public snapshots predate this extension; this supplied archive is the complete reproduction source. The extension compares conditionally supplied physiological inputs, not prospective clinical forecasts.


The observation-design extension is specified in experimental_validation/REVIEW_PROTOCOL.md. It adds seven result CSVs, Figure 12 and six tests (55 total). All 81 result CSVs are compared. The empirical resampling holds fitted parameters and test inputs fixed; its percentile ranges are descriptive and do not correct model selection or assert population confidence coverage. Independent gas-input calculations are sensitivity analyses, not new observed data. Figure-only export for Figure 12 is `python experimental_validation/code/review_figures.py`.

The applicability_extension adds seven diagnostic CSVs, 10 tests and Figure 9. It is an exploratory audit of observed PH states, not new patients or independent clinical validation. See its PROTOCOL.md and README.md.

The certainty_extension adds nine CSVs, 13 tests and Figures 10–11. It evaluates common multi-state model constraints, finite countermodels and capacity exclusion. Older section counts refer to their individual modules. No new patients or independent clinical validation are claimed.

Measurement extension: run `python measurement_extension/code/reproduce_measurement.py`. Four additional CSV outputs and six tests are included in the full runner. The preceding 142-result-CSV and 131-test totals become 146 and 137. Measurement error boxes are stipulated and do not establish clinical coverage.
